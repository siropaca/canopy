# フェーズ 5: 常用で出たもの

## 目的

フェーズ 4 の完了条件に残した「常用しながら気づいたことを書き出す」から回ってきた 4 件を片付ける。  
毎日触って初めて分かった、見た目のずれと足りない操作。

## 前提

- [../specs/ui.md](../specs/ui.md) の「ツリー」「サイドバー」「コンテキストメニュー」
- [../design-system.md](../design-system.md) の「アイコン」「インジケーターの色と並び」
- [adr/0007-v1-scope.md](../adr/0007-v1-scope.md) — v1 の境界。**ブランチの削除をここから外す**
- [adr/0009-concurrency-and-refresh.md](../adr/0009-concurrency-and-refresh.md) — 取り直しの規定

## やること

### 1. インジケーターの寸法と余白を揃える

- [x] 未コミットの `●n` が、behind / ahead と**大きさも間隔も違う**。
      丸はテキストの 1 文字 (13px) で数字との間隔が 0、矢印は 11px の SVG で間隔 3px
- [x] 丸を SVG に置き換えて、枠を 11px・間隔 3px に揃える。リポジトリ見出しのバッジ (10px) も同じ
- [x] **モックも同じ形に直す。** モックが `●` を書いているので、CSS の突き合わせでは出なかった

### 2. ツリーの並び順を変える

- [x] **葉を先に、ディレクトリを後に出す。** いまは逆で、ルート直下の `develop` / `main` が
      `feat/` `feature/` の下に沈む。毎日見るのは前者
- [x] 仕様 ([../specs/ui.md](../specs/ui.md) の「ツリー」) とモックも直す

### 3. 更新 (フェッチせずに状態を取り直す)

- [x] サイドバーに「更新」を置く。押すと全リポジトリのスナップショットを取り直す
- [x] **ウィンドウが前面に戻ったら自動で取り直す。** フェーズ 4 で入れた可視性の仕組みに乗せる
- [x] **`.git` を監視して自動で取り直す。** ターミナルで操作しても、ウィンドウを見たまま反映される
- [x] 監視は `notify` クレート。**まとめて 1 回にする** (git の 1 操作で何十ファイルも動く)
- [x] 自分が走らせた操作の分では取り直さない。取り直しは操作の側が既にやっている
- [x] 判断は [adr/0022-auto-refresh.md](../adr/0022-auto-refresh.md) に書く

### 4. ローカルブランチの削除

- [x] gone のブランチが片付けられない。**`git branch -d` を入れる**
- [x] マージされていなければ git の失敗をそのまま見せる。**黙って `-D` に落とさない**
- [x] ダイアログで「マージされていなくても削除」を選べる。選ぶとボタンが赤くなる
- [x] サイドバーの「ブランチの削除」を有効にする (いまは v2 でグレー)
- [x] [adr/0007-v1-scope.md](../adr/0007-v1-scope.md) の「入れない」から外す。見直しの ADR を書く

## テスト

| 層 | 内容 |
| --- | --- |
| フロント ユニット | 並び順。葉が先、ディレクトリが後。どちらも名前順のまま |
| フロント ユニット | モックと実装の CSS の突き合わせ (既存のテストが丸の変更を拾う) |
| コンポーネント | インジケーターの構造。3 つとも「アイコン + 数字」で同じ形 |
| フロント ユニット | 更新のアクション。実行中のリポジトリを二重に読まない |
| フロント ユニット | 削除の有効条件。現在のブランチと別ワークツリーのものは無効 |
| Rust ユニット | 削除のコマンド組み立て (`-d` と `-D`) |
| Rust 統合 | 実物のリポジトリで、マージ済みは消えて未マージは失敗すること |
| Rust ユニット | 監視のまとめ方 (何件来ても 1 回に畳む) |
| 手動 | ターミナルでプッシュして、ウィンドウを見たまま反映されること |

## 完了条件

- [x] インジケーターの 3 つが同じ寸法・同じ間隔で並ぶ
- [x] ルート直下のブランチがディレクトリより上に出る
- [x] ターミナルで操作した結果が、ボタンを押さなくても反映される
- [x] gone のブランチを画面から消せる

## やらないこと

- リモートブランチとタグの削除。ローカルの掃除が目的なので、まずローカルだけ
- 複数選択してまとめて削除。1 つずつで足りるかを使って確かめてから
- 監視の対象をワークツリーの中身まで広げること。`node_modules` を抱えるので現実的でない。
  ファイルを編集しただけの未コミットは、次の更新まで反映されない

## 確かめたこと

| 何を | どう |
| --- | --- |
| 3 つの引き金 | 実機で確認した。`.git` を触ると `repos_changed` が飛んで**そのリポジトリだけ**取り直す。`Cmd+H` で隠すとイベントは飛ぶが取り直さない。前面に戻すと 11 件を取り直す |
| 監視が本当に届くか | 実物の FSEvents で確認した (`src-tauri/tests/watching.rs`)。ターミナルのコミットが届くこと、1 操作が 1 回に畳まれること (2 回目が来ないことまで) |
| パスの噛み合わせ | `--git-common-dir` を `canonicalize` していないと 1 件も拾えない。実際に外して落ちることを確認した (macOS の `/var` -> `/private/var`) |
| 自分の操作の分 | 書き込みの**間ずっと**黙ることを、遅い `post-checkout` フックを噛ませて確認した。猶予に入っただけでは通らない形にしてある |
| モック | ブラウザで確認した。更新ボタン、選択で有効になる削除、強制を選んだときの赤いボタンと注意、葉が先の並び |
| テストに歯が立っていること | 実装を **20 通り**壊して全部落ちることを確認した。レビューでさらに **11 通り**壊して素通りしたものは、テストを足して落ちるようにした |

## レビューで出たこと

5 観点をサブエージェントに投げた (仕様の一致 / 正しさ / テスト / 設計 / ドキュメント)。  
指摘は 52 件 (仕様 10 / 正しさ 7 / テスト 13 / 設計 7 / ドキュメント 15)。

### 直したもの

| 指摘 | 対応 |
| --- | --- |
| 監視の経路が誰にも見られていない。`watch_targets` を空にしても 300 件が全部緑 | `AppState::watch_targets` のテストを足した。`pump` から `AppHandle` を外して `emit` を受ける形にし、畳み方と握りつぶしを本物のループで見るテストを足した |
| 書き込みの「間ずっと」黙るかを見ていない。取った直後に手放しても通る | 遅い `post-checkout` を噛ませて、**遠い未来の時刻**で `is_muted` を聞くテストにした。猶予に入っているだけなら false になる |
| 削除の force が IPC まで届いているかを見ていない | `useRowActions` のテストと、サイドバー → ダイアログ → `deleteBranch` を通す配線のテストを足した (`src/app/wiring.test.tsx`) |
| サブモジュールの `modules/<名前>/objects/` が除外に引っかからない | 先頭の `modules/<名前>/` をはがしてから見るようにした。入れ子も同じ |
| 静穏の起点が「最後のイベント」であることを見ていない | 締め切りが後ろへ延びることを見るテストを足した |
| 「まとめる」統合テストが、まとめを見ていない (1 回目を取るだけ) | **2 回目が来ないこと**まで見るようにした |
| ロックと握りつぶしを 2 回に分けて取っている | `AppState::begin_write` が 1 回で取る形にした。書き込みを足したときに片方だけ忘れる余地を消す |
| 監視の張り直しが 3 箇所に散っている | `watch_registered` の 1 本にした |
| 「実行中か」の判定が 2 箇所にある | `useRepoStore` の `isRunning` に寄せた |
| 「更新」に重複排除が無い。連打で 110 本積まれる | 読んでいる最中の分は積まず、**1 回だけやり直す**形にした (捨てると最後の変化を取りこぼす) |
| 隠れている間も `.git` の変化で取り直す。既存の仕様と矛盾する | 隠れている間は捨てるようにした。戻ったときに全件読み直すので取りこぼさない |
| 期限切れの覚えが、リポジトリを消すと回収されない | `Quiet::sweep` を足して、出すたびに落とすようにした |
| 削除のコマンド組み立てを見るテストが無い | `-d` / `-D` の実際の文字列を固定した |
| `canDelete` の「実行中は無効」を誰も縛っていない | 述語の一覧と個別のテストに足した |
| インジケーターのアイコンの取り違えを通す | どのアイコンかを**形**で見るようにした (期待値は本物のアイコンから取る) |
| ディレクトリの名前順が押さえられていない | 2 つ以上のディレクトリが並ぶケースを足した |
| `onReposChanged` の購読チャンネルを誰も見ていない | `src/ipc/events.test.ts` を足した |
| README が削除と更新を書いていない。v2 の一覧に削除が残っている | 直した。`docs/specs/ui.md` の「v2 以降」も直した |
| 採用済みの ADR-0007 の本文を書き換えている | 本文は当時のまま戻して、注記だけ残した |
| ADR-0021 の `Registry::prune` の記述が実装と違う | 実際に残るもの (ディレクトリの鍵) に書き直した |
| モックが削除の無効条件と強制の見た目を持っていない | サイドバーの有効・無効、強制でボタンが赤くなること、注意の表示を入れた |
| モックのソートが数値順でない | `Intl.Collator("ja", { numeric: true })` に揃えた |
| ダイアログの補足が `--force` で、実行する `-D` と字面が合わない | `-D` に揃えた (仕様・実装・モック) |
| 新しい定義を差し込んで、前の関数の doc コメントを奪っている (3 箇所) | 直した |

### 見送ったもの

| 指摘 | 理由 |
| --- | --- |
| `useSubscription` の「トップレベルの関数だけを渡す」が型で縛れていない | 縛る形にすると引数がキーになって読みにくくなる。呼び出しは 2 箇所で、どちらも正しい。コメントで残す |
| `notify` が `watch` のたびにストリーム全体を張り直す | クレートの実装なのでこちらでは変えられない。差分だけ張る形は残す (穴の数が減る)。取りこぼしは他の 2 つの引き金が拾う。[../pitfalls.md](../pitfalls.md) に書いた |
| 猶予の 1.5 秒に外で起きた変化が落ちる | 猶予を短くすると自分の操作の分を拾う。落ちる分は「更新」と前面復帰で拾えるので、[../adr/0022-auto-refresh.md](../adr/0022-auto-refresh.md) の影響に書いて残す |
| `watching.rs` が実時間に依存する | 届かなければ 10 秒待って落ちる。**素通りではなく失敗に転ぶ**ので危険度が低い。5 回連続で 1.8〜2.3 秒だった |
