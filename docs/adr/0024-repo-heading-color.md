# ADR-0024: リポジトリ見出しに色を付けられるようにする

- ステータス: 採用
- 日付: 2026-09-25

## 背景

リポジトリ見出しは全部同じグレー (`--head`) で描いている。  
11 リポジトリを並べて展開すると、名前を読まないとどのリポジトリの中にいるのかが分からない。  
固定した見出し ([../specs/ui.md](../specs/ui.md) の「リポジトリ見出し」) も同じグレーなので、スクロール中に見分ける手がかりにならない。

常用していて、見出しに色を付けて見分けたいという要望が出た。

## 決定

**リポジトリ見出しの行の背景を、決まった 6 色から選んで塗れるようにする。**

- 選べるのは `なし` と 赤・オレンジ・黄・緑・青・紫 の 7 つ。任意の色は選べない
- 選ぶのはリポジトリ見出しのコンテキストメニューのサブメニュー `見出しの色`
- 保存は `UiState.repo_colors` に「リポジトリ id → 色の名前」で持つ ([../specs/data-model.md](../specs/data-model.md))
- 色の値はトークン (`--head-<色>`) に置く。保存するのは名前だけで、値は持たない
- **選択・薄い表示 (ヒットなし・エラー) はこれまでどおり色の上に乗る。** 色は既定のグレーの代わりにだけ入る
- **実行中は色を残す。** 見出しの文字だけ薄くして、背景は塗り替えない
- **色を選んだら選択を外す**
- 固定した見出しも同じ色で描く

## 理由

- **背景を塗るのが遠目でいちばん効く。** 見出しは 1 行まるごと面なので、面の色を変えればスクロールしながらでも拾える
- **決まった色から選ぶ。** 色は文字 (`--fg-strong`) を白で乗せる前提で、どれも白が読める暗さに揃えてある。  
  任意の色を許すと、明るい色で見出しの文字が読めなくなる
- **名前で保存する。** hex で保存すると、トークンの値を直したときに保存済みの見出しが古い色のまま残る
- **`UiState` に置く。** 色は並び順や折りたたみと同じく、フロントが持つ表示の好み。  
  登録情報 (`RepoRegistration`) に入れると、色を変えるたびに専用のコマンドが要る
- **知らない色の名前は読み捨てる。** 新しい版で色を増やしたあと古い版で開いても、設定ファイル全体が「壊れている」扱いにならない  
  ([ADR-0016](0016-store-without-plugin.md))
- **選択の色を優先する。** 選んでいる見出しが分からなくなるのがいちばん困る。  
  薄い表示も「検索に当たらない」「読めない」を伝えるためのもので、色で消さない
- **実行中は背景を塗り替えない。** 一括フェッチは全リポジトリを実行中にするので、塗り替えると色で見分けたい場面で全部の見出しがグレーになる
- **色を選んだら選択を外す。** 右クリックした見出しは選択中になり、選択の色が見出しの色より勝つ。  
  外さないと、何色になったかが他の行を押すまで見えない

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| 左端に色の帯を付ける | 選択中も色が見えるが、細いので遠目に拾いにくい。依頼は「行に色をつける」 |
| 背景と左端の帯の両方 | 見出しの要素が増えてうるさくなる。選択中に色が隠れるのは受け入れる |
| 文字の色を変える | 見出しは太字の白で、色を変えると読みにくくなる。面ほど目立たない |
| 任意の色を選べるようにする | 白い文字が読めない色を選べてしまう。カラーピッカーを持つとメニューに収まらない |
| hex で保存する | トークンを直しても保存済みの見出しが追従しない |
| 登録情報 (`RepoRegistration`) に持つ | 見た目の好みのために専用のコマンドが要る。`UiState` なら今の保存の流れに乗る |
| 実行中もヒットなしと同じく背景を塗り替える | 一括フェッチの間じゅう色が消える。実行中かどうかは文字の薄さとステータスバーで分かる |
| 色を選んでも選択を残す | 選択の色が勝つので、塗った結果が他の行を押すまで見えない |
| サブメニューで今の色に印を付ける | 今の色は分かるが、塗った結果は選択を移すまで見えない |

## 影響

- トークンが 6 つ増える (`--head-red` / `--head-orange` / `--head-yellow` / `--head-green` / `--head-blue` / `--head-purple`)。  
  値は [../design-system.md](../design-system.md)
- 見出しの背景の優先順位は「選択 (フォーカスあり) > 薄い表示 > 選択 (フォーカスなし) > 色 > 既定」になる
- 実行中の見出しは、色を付けていなくても背景が変わらなくなる (前は薄い表示と同じ背景だった)。文字が薄くなるのは同じ
- 色の一覧の源は Rust の `RepoColor`。フロントの一覧 (`src/shared/lib/repoColors.ts`) はその型で縛り、CSS・トークン・モックの突き合わせはその一覧から回す
- リストから削除したリポジトリの色は、`expanded` と同じく Rust 側で捨てる
- 色を変えるのは git を実行しない操作なので、実行中でも変えられる
