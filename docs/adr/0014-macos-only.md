# ADR-0014: 対応プラットフォームは macOS のみ

- ステータス: 採用
- 日付: 2026-08-21

## 背景

Tauri はクロスプラットフォームだが、このツールは自分の作業環境で使うためのもの。  
どこまでを対象にするかを決めていなかった。

## 決定

**macOS のみ。** Windows と Linux は対象外にする。

- ビルドは macOS 向けだけ作る
- CI も macOS のランナーだけで回す
- プラットフォーム分岐のコードを書かない。macOS を前提にして書く

## 理由

- 使うのは自分の Mac だけ。他の環境で動かす予定がない
- [ADR-0011](0011-residency.md) の常駐はメニューバー前提で、macOS 固有の作り
- 分岐を書かない分だけ実装が薄くなる。動作確認も 1 環境で済む
- 必要になったら、そのとき対象を広げる ADR を書く

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| 最初からクロスプラットフォームで書く | 使わない環境のために実装と確認のコストを払うことになる |
| Linux も対象に含める | 常駐の作りが環境ごとに変わる。今は不要 |

## 影響

- パスの扱い、`open` コマンド、メニューバーの実装を macOS 前提で書ける
- 署名と公証は当面やらない。自分の Mac で動かすだけなので、ad-hoc 署名か quarantine 属性の除去で済ませる
- 将来対象を広げるときは、常駐の作りとパスまわりを見直す必要がある
