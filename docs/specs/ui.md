## 画面の構成

```
┌──┬──────────────┬───────────────────────────┐
│  │ 検索 (固定)   │                           │
│side├─────────────┤        詳細ペイン          │
│bar │ ツリー       │                           │
│  │              │                           │
├──┴──────────────┴───────────────────────────┤
│ コンソール (開閉可)                           │
├─────────────────────────────────────────────┤
│ ステータスバー                                │
└─────────────────────────────────────────────┘
```

- ヘッダーは持たない
- 詳細ペインは常に表示する。切り替えは持たない
- ツリーと詳細の境界はドラッグでリサイズできる (240〜760px)
- 検索欄はツリー領域の最上部に固定する。ツリーをスクロールしても残る
- **キーボード操作は持たない。** v1 はマウスだけで完結させる (意図的な割り切り)。例外はダイアログ内の Enter (確定) と Esc (キャンセル)、検索欄への文字入力だけ ([../adr/0008-no-keyboard-shortcuts.md](../adr/0008-no-keyboard-shortcuts.md))

| ツリー表示 | すべて展開 (ローカルのみ) | 常に有効 | |
| | すべて展開 | 常に有効 | |
| | すべて折りたたむ | 常に有効 | |
| | グループ化 ディレクトリ | 常に有効 | トグル。既定オン |
| | ローカルのみ表示 | 常に有効 | トグル。既定オフ |
| リポジトリ | リポジトリを追加 | 常に有効 | 押すとフォルダ選択が開く |

## ツリー

### 構造

```
リポジトリ名                    ← 折りたたみ可
  ローカル                      ← 折りたたみ可
    feature/                   ← ディレクトリ (グループ化オンのとき)
      rec-482-repeat-offer
    develop
  リモート                      ← 折りたたみ可。既定で閉
    origin/
      feature/
        ...
  タグ                          ← 折りたたみ可。既定で閉。タグが無ければ出さない
```

- `HEAD (現在のブランチ)` の行は持たない
- ローカルは既定で開、リモートとタグは既定で閉
- リモートとタグは中のディレクトリまで畳んだ状態にする。1 段ずつ開く
- 括り行に件数は出さない
- 親を閉じたら配下も全部閉じる。開き直したとき子は閉じたまま
- グループ化をオフにすると `origin/feature/xxx` のように完全な名前を 1 行で出す

並び順は git の出力順ではなく、名前でソートする。

- ディレクトリを先に、葉を後に出す
- どちらも名前で辞書順 (ロケール考慮)。**数字は数として比べる** (`rec-2` が `rec-10` より先)
- ソートに使う名前は、グループ化オンなら**最終セグメント**、オフなら**完全な名前**

インデントの上限は 12 段。  
ブランチ名は何段でも深くできるので、それより深い行は 12 段目と同じ位置に出す (行は消さない)。

### ブランチ行

```
[アイコン] ブランチ名  ●2  ↙3  ↗1  gone  ⧉ワークツリー名
```

| 要素 | 出る条件 |
| --- | --- |
| オレンジのタグアイコン | メインのワークツリーの現在ブランチ |
| `●n` | そのブランチのワークツリーに未コミットの変更がある。n は変更ファイル数。ホバーで `未コミット n ファイル` |
| `↙n` | behind が 1 以上 |
| `↗n` | ahead が 1 以上 |
| `gone` | 追跡ブランチが消えている。この行のプルは無効にする (`couldn't find remote ref` で必ず失敗する) |
| `⧉名前` | 別のワークツリーにチェックアウトされている。名前はワークツリーのディレクトリ名。チェックアウトは無効。プルはそのワークツリーで実行する |

アイコンだけでは意味が読めないので、ホバーで文言を出す。

| 要素 | ホバーの文言 |
| --- | --- |
| `●n` | `未コミット n ファイル` |
| `↙n` | `n コミット遅れている` |
| `↗n` | `n コミット進んでいる` |
| `gone` | `追跡ブランチが消えている` |
| `⧉名前` | `ワークツリー <名前> にチェックアウト済み` |

現在ブランチを太字にしない。  
名前が長い場合は末尾を省略し、ホバーで全体を出す。

### 読み込み中とエラー

起動時は保存済みのリポジトリ一覧から**見出しを全件すぐに描く。**  
中身は届いた分から埋める。全部揃うまで待たない。

| 状態 | 見え方 |
| --- | --- |
| 読み込み中 | 見出しだけ。中身は空。見出しの右に薄く `読み込み中` |
| 完了 | 通常表示 |
| エラー | 見出しを薄くして、右に理由を出す (`ディレクトリが見つかりません` など) |

ステータスバーの合計値は、読み込み中のリポジトリが 1 つも無くなるまで `-` を出す。  
0 → 途中 → 確定と 2 回跳ねるのを避ける。  
**エラーのリポジトリは待たない。** 待つと 1 つ壊れているだけで永久に `-` になる。  
その代わり、エラーのリポジトリのブランチ数は合計に入らない。

一覧そのものを読み終えるまでは、リポジトリ数も `-` にする。  
「まだ読んでいない」と「0 件登録されている」は違う状態。

エラーのリポジトリは行を消さない。消すと `repo_order` に id が残って不整合になり、原因も分からなくなる。

リポジトリ単位ではなく、ツリー領域全体に出す表示が 2 つある。

| 状態 | 見え方 |
| --- | --- |
| 登録が 0 件 | ツリー領域の中央に薄く `リポジトリが登録されていません` |
| 設定ファイルが読めない | 同じ位置に理由を出す (`設定の中身が壊れています ...`)。**握りつぶさない** ([../adr/0016-store-without-plugin.md](../adr/0016-store-without-plugin.md)) |

読み込み中はどちらも出さない。一瞬「登録されていません」が出るのを避ける。

### detached HEAD

タグのチェックアウトで detached HEAD になる。  
このとき現在ブランチが存在しないので、オレンジのタグアイコンはどのブランチにも付かない。

- リポジトリ見出しに `detached: <参照名>` を出す
- 詳細ペインの「現在」は `detached (<参照名>)` と出す
- 「選択対象をプル」は無効にする
- **元のブランチに戻る手段を用意する。** リポジトリ見出しのメニューに「直前のブランチに戻る」(`git checkout -`) を置く

これが無いと、タグをダブルクリックした時点で「壊れた」ように見えて戻れなくなる。

### リポジトリ見出し

- リポジトリ名を表示する
- サマリのバッジ (`●n` / `↙n` / `↗n`) は**折りたたんでいるときだけ**出す
- `●n` はメインのワークツリーの変更ファイル数。他のワークツリーの変更は含めない
- `↙n` `↗n` はローカルブランチの behind / ahead の**合計**。ブランチ数ではない
- 見出しはドラッグで並び替えられる。挿入位置に線を出す
- 挿入線は「そのリポジトリのブロック全体の前後」に描く。展開中のリポジトリの見出しの下に線を出すと、配下の行の後ろに着地して線と結果がずれる
- ドラッグできるのはリポジトリ見出しだけ。ブランチの行はドラッグできない
- 並び替えても折りたたみ状態は保つ

### 操作

| 操作 | 結果 |
| --- | --- |
| クリック | 選択 |
| シェブロンのクリック | 選択 + 開閉。**v1 で唯一のシングルクリックでの開閉手段** |
| ダブルクリック (折りたためる行) | 開閉 |
| ダブルクリック (ブランチ・タグ) | チェックアウト |
| 右クリック | 選択 + コンテキストメニュー |

### 検索

- ブランチ名とタグ名を対象に、全リポジトリを横断して絞り込む
- **検索中は折りたたみを無視して全ノードを開く。** リポジトリ見出し・括り・ディレクトリすべて。リモートとタグも開く
- 折りたたみ状態は裏で保持する。検索を消すと元の状態に戻る
- 検索中にシェブロンを押しても見た目は変わらない (状態だけ変わる)
- **ヒットが無いリポジトリも見出しだけ残す。** 見出しは薄く表示する
- ローカルのみ表示がオンのときは、リモートとタグを検索対象から外す

## コンテキストメニュー

各項目が実行する git コマンドは [git-operations.md](git-operations.md) にある。  
特に「プル」は選択対象で実行内容が変わる。現在ブランチなら `git pull --rebase`、他のローカルブランチなら**チェックアウトせずに早送りする** `git fetch origin <名前>:<名前>`。

メニューを出すのは**リポジトリ見出し、ブランチ、タグ**だけ。  
`ローカル` / `リモート` / `タグ` の括り行とディレクトリ行では出さない (選択だけ)。

v2 の項目はグレーで出す。押しても何も起きない。

### 文言のルール

画面に出す文字はこれに従う。メニューに限らず全体に適用する。

- `...` (三点リーダー) を付けない
- 「更新」ではなく「プル」と書く。git の用語に寄せる
- 「フェッチ」はカタカナで統一する。UI に `fetch` と英語で出さない (コマンド名やコードの識別子は英語のまま)
- ダイアログのプライマリボタンは `OK` ではなく操作名 (`プッシュ` / `名前の変更`)
- 一般的でない漢語を使わない。「走査」ではなく「まとめて追加」

## 詳細ペイン

選択したものに応じて内容を変える。

選択が折りたたみや検索で画面から消えた場合、詳細ペインは「ブランチを選択」に戻り、サイドバーの選択依存のボタンも無効になる。  
選択そのものは保持するので、開き直すと詳細も有効状態も戻る。  
つまりボタンの有効条件は「選択の種類」ではなく「**画面に見えている**選択の種類」。

| 選択 | 見出し | 項目 | ボタン |
| --- | --- | --- | --- |
| なし (または選択が非表示) | — | — | 「ブランチを選択」と表示 |
| リポジトリ | リポジトリ名 / パス | origin、ブランチ、現在、未コミット | フェッチ / プル / パスをコピー / リストから削除 |
| リポジトリ (読み込み中 / エラー) | 同上 | 状態 (`読み込み中` かエラーの理由) | リストから削除 |
| 現在のブランチ | ブランチ名 | 種別、追跡、差分、最終コミット、未コミット | プル / プッシュ / 名前をコピー |
| 他のローカル | 同上 | 同上 + ワークツリー (別のワークツリーにあるときだけ) | チェックアウト / チェックアウトとプル / プッシュ / 名前をコピー |
| リモート | 同上 | 種別、最終コミット | チェックアウト / 名前をコピー |
| タグ | タグ名 | 種別、最終コミット | チェックアウト / タグ名をコピー |

括り行 (`ローカル` / `リモート` / `タグ`) とディレクトリ行を選んでいるときは「ブランチを選択」のまま。  
コンテキストメニューを出さない行と揃える。

見出しは アイコン + 名前、その下にリポジトリ名。現在ブランチなら ` — 現在のブランチ` を付ける。

`ワークツリー` の行は現在のブランチには出ない。  
git は同じブランチの二重チェックアウトを拒否するので、`is_current` と `worktree_path` は同時に立たない。

> モックはタグとリモートブランチでも `追跡` (`—`) と `差分` (`最新`) の行を出していた。  
> どちらも追跡先を持たないので出さない形に直した (モックも修正済み)。

未コミットの変更があるときは、ボタンの下にファイル一覧を出す。

- 見出しは `未コミットの変更 (n)`
- 各行はステータス文字 + パス。ステータスで色を変える (`M` オレンジ / `A` 緑 / `D` 赤 / `R` 青 / `??` とその他 グレー)
- 20 件を超えたら `他 n 件` にまとめる
- **選択したブランチのワークツリーの変更**を出す。リポジトリ全体ではない

## 実行中の扱い

操作は数百 ms から数秒かかる。  
楽観的更新をしない方針なので、何も出さないと**完全に無反応**になり、ユーザーは同じ操作をもう一度実行する。

そのリポジトリに実行中の操作があるあいだ、次を無効にする。

- そのリポジトリの行のダブルクリック
- そのリポジトリのコンテキストメニューの操作項目
- 詳細ペインのボタン
- サイドバーのフェッチとプル (対象がそのリポジトリのとき)

行は薄く表示する。スピナーは出さない。  
他のリポジトリの操作は妨げない。

## 操作したあとの更新

操作が成功したら、そのリポジトリの状態を**取り直して**表示を更新する。  
フロントで数値を書き換える楽観的更新はしない ([../architecture.md](../architecture.md))。

- プッシュが成功したら ahead は取り直した結果として 0 になる
- 名前を変更したら、新しい名前の行を選択したままにする
- リポジトリをリストから削除したら選択を外す

> モックはプッシュ後に `ahead` を 0 に書き換え、名前変更もその場でデータを差し替えている。  
> これは git を実行しないモックだからで、実装では真似しない。

## コンソール

- 画面下部。開閉はサイドバーのボタンか、パネル右端の `✕`
- リポジトリごとのタブ。出力があったリポジトリの分だけ増える
- タブは `✕` で個別に閉じられる。全部閉じてもパネルは開いたまま
- タブが無いときは左端に `コンソール` と出す。本文は `出力はまだありません`
- 右端に `読み取り専用` と表示する。出力エリアのホバーで `このビューは読み取り専用です`
- 選択とコピーはできる。入力はできない
- 失敗があったタブには赤いドットを出す。そのタブを開くと消える

行の形式。

```
02:04:17.543: [/Users/dev/Projects/acme/acme-api] git pull --rebase
error: cannot pull with rebase: You have unstaged changes.
```

コマンド行は明るいグレー、エラー行は赤、通常の出力は落としたグレー。

## トースト

右下に積む。最大 6 件。

| 種別 | 見た目 | 表示時間 |
| --- | --- | --- |
| 成功 | 青い丸の `i` + 実行したコマンド | 4 秒 |
| 一括操作の完了 | 1 件に集約する。`11 リポジトリをフェッチしました (失敗 2)` | 4 秒 |
| 失敗 | 赤い丸の `!` + 失敗の要約 + `詳細を見る` | 9 秒 |

`詳細を見る` を押すと、そのリポジトリのタブでコンソールが開く。

**一括フェッチはリポジトリごとにトーストを出さない。** 11 件出すと上限 6 を超えて失敗のトーストが押し出される。  
一括操作の実行中はそのボタンを無効にする。

## ダイアログ

共通の形。

- タイトルバー (下に区切り線)。タイトルは太字で対象名を含める
- ウィンドウ操作のボタンは持たない (アプリ内のダイアログなので)
- ボタンは右下。`キャンセル` → プライマリの順
- プライマリのラベルは操作名。`OK` にしない
- 背景のオーバーレイをクリックすると閉じる
- ダイアログ内でだけ Enter で確定、Esc でキャンセルを受ける

### ブランチ名の変更

```
タイトル: ブランチ <名前> の名前変更
ブランチ名: [____________]
                    キャンセル  名前の変更
```

### プッシュ

やや広くする。

```
タイトル: コミットを <リポジトリ名> にプッシュ

<ブランチ>  →  origin : <ブランチ>
n 件のコミットをプッシュします
  ● <ハッシュ>  <コミットメッセージ>
  ● <ハッシュ>  <コミットメッセージ>

[ ] 強制プッシュ  --force-with-lease
                    キャンセル  プッシュ
```

- コミット一覧は枠を付けない。左にノードを置いて縦線でつなぐ (git のログの見え方)
- 強制プッシュをオンにすると、プライマリボタンが `強制プッシュ` に変わり赤くなる
- **ahead が 0 のときは強制プッシュのチェックボックス自体を無効にする。** そのまま実行するとリモートを巻き戻して、他人のコミットを消す
- ahead も behind もあるときは、**失われる behind 側のコミット一覧を出して**確認を一段増やす
- ahead が 0 のときは `プッシュするコミットはありません`
- 追跡ブランチが無いときは `追跡ブランチが無いので新規に作成します`

### リポジトリを追加

OS のフォルダ選択を開く。  
アプリ独自のダイアログは作らない。

## スクロール

**ネイティブのスクロールバーはどこにも出さない。**  
見え方は [../design-system.md](../design-system.md) の「スクロール」にある。

振る舞いはこう決める。

- ツリーとコンソールは仮想スクロールにする
- 選択行は、折りたたみなどで行の並びが変わったときだけ画面に入れ直す。**クリックではスクロールしない**
- スクロール量から全体の件数を推測させない前提で設計する

## ステータスバー

```
11 リポジトリ   ローカル 24 / リモート 289   ↙56 (2 repo)   ↗7 (4 repo)   未コミット 8 repo   worktree 2
```

数値の定義。

| 表示 | 定義 |
| --- | --- |
| `n リポジトリ` | 登録しているリポジトリ数 |
| `ローカル n / リモート n` | 全リポジトリのブランチ数の合計 |
| `↙n (m repo)` | n は behind の総和、m は behind が 1 以上あるリポジトリ数 |
| `↗n (m repo)` | 同じく ahead |
| `未コミット n repo` | メインのワークツリーに変更があるリポジトリ数。**他のワークツリーだけが変更されているリポジトリは数えない** |
| `worktree n` | ブランチが紐づくワークツリーの数。detached と bare、`prunable` / `locked` は数えない ([data-model.md](data-model.md) の `Worktree`) |

色はツリーと揃える。  
behind は青、ahead は緑、未コミットはオレンジ、worktree は紫。
