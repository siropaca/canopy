# ADR-0004: 一覧は仮想スクロールにする

- ステータス: 採用
- 日付: 2026-08-21

> 判断は維持。実装上の細部 (スクロールバーの描き方、ドラッグ並び替えとの両立) は [ADR-0012](0012-scrollbar-and-virtualization.md) で決めた。

## 背景

11 リポジトリでリモートを全部開くと 400 行を超える。  
コンソールの出力は使うほど増え続ける。  
スクロールバーを目立たせたくないという見た目の要求もある。

## 決定

ツリーとコンソールを仮想スクロールにする。  
ライブラリは `@tanstack/react-virtual` を使う。

## 理由

- 行数が増えても描画コストが一定に保たれる
- スクロールバーを細く自前で制御しやすい
- 行高が固定 (21px) なので、仮想化の実装が単純になる

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| そのまま全件描画する | コンソールが伸び続けると破綻する |
| 自前で実装する | 行の可変高やスクロール復元で必ず粗が出る |

## 影響

- ツリーは「表示される行の配列」に平坦化してから描画する。DOM の入れ子で階層を作らない
- 平坦化した配列はインデントの深さを持つ。折りたたみは平坦化の段階で解決する
- スクロール位置の復元、選択行へのスクロールは仮想化前提で実装する
- 「スクロールバーの長さで全体量を推測する」使い方はできなくなる。件数は別の形で見せるか、見せない
