# ADR-0012: スクロールバーを自前で描く。仮想化との両立

- ステータス: 採用
- 日付: 2026-08-21

> **ドラッグ並び替えの部分だけ [ADR-0019](0019-reorder-without-dnd-kit.md) が置き換えた。**  
> この文書の「決定」の 3 節目、「理由」の 3 つ目、「検討した他の案」の
> 「並び替えを自前で書く」の行、「影響」の `@dnd-kit/*` は**もう根拠にならない。**  
> **`@dnd-kit/*` の追加は承認済みではない。** 依存は増やさず自前で書いた。  
> スクロールバーと仮想化の決定はそのまま生きている。

## 背景

「スクロールは仮想スクロールにする (スクロールバーを目立たせたくない)」という要望の本来の意図は、**web 標準のスクロールバーを画面に出したくない**こと。

[ADR-0010](0010-virtualize-console-only.md) はこれを性能の要望と読み違えて「実測では仮想化は不要」と結論づけたが、意図が違うので破棄した。

ただし ADR-0010 が挙げた問題は実在する。  
仮想化すると画面外の行が DOM から消えるので、リポジトリのドラッグ並び替えが素直に書けない。

## 決定

### スクロールバー

- **ネイティブのスクロールバーは表示しない。** 自前のスクロールバーを描くライブラリを使う
- 候補は `overlayscrollbars-react`。ネイティブを隠して独自のつまみを重ねることだけを目的にしたライブラリ
- 見た目は IDEA に寄せる。細く、操作中だけ濃くなる

### 仮想化

- **ツリーもコンソールも仮想化する。** `@tanstack/react-virtual`
- スクロール領域は自前スクロールバーのビューポート要素にする。仮想化のスクロール要素として渡す
- 行の平坦化 (`flatten()` で `RowNode[]` を作る) は仮想化の前提として維持する

### ドラッグ並び替え

> **この節の「dnd-kit を使う」は [ADR-0019](0019-reorder-without-dnd-kit.md) が置き換えた。**  
> dnd-kit の衝突判定は DOM の矩形を見るので、仮想化で画面外のリポジトリがドロップ先にならない。  
> 「インデックスから決める」「ブロック境界に線を描く」「対象は見出しだけ」はそのまま生きている。

仮想化と両立させるため、DOM のヒットテストに頼らない。

- `@dnd-kit/core` + `@dnd-kit/sortable` を使う。仮想化リストでの並び替えと端でのオートスクロールに対応している
- ドロップ位置は**行の DOM ではなく仮想化リストのインデックス**から決める
- 挿入線はリポジトリの**ブロック境界**に描く。展開中のリポジトリの見出しの下に線を出すと、配下の行の後ろに着地して線と結果がずれる
- 並び替えの対象はリポジトリ見出しだけ。ブランチの行はドラッグできない

## 理由

- 意図が「スクロールバーを出さない」なので、CSS でネイティブを細くするだけでは足りない。`::-webkit-scrollbar` を当てても、それはネイティブのスクロールバーのまま
- 自前スクロールバーは仮想化と競合しない。スクロール領域を明示的に渡せば済む
- ドラッグ並び替えは自前で書くと、オートスクロール・衝突判定・キャンセル処理を全部持つことになる。dnd-kit はそこを埋めるためのライブラリ
- 依存は 2 つ増えるが、どちらも「自分で書くと必ず粗が出る」領域

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| `::-webkit-scrollbar` で細くする | ネイティブのスクロールバーが出ること自体は変わらない |
| Radix の `ScrollArea` | 使える。ただしスクロールバー以外の機能も抱えるので、目的が 1 つのライブラリを選んだ |
| ツリーの仮想化をやめる (ADR-0010) | 要望の意図と合わない |
| 並び替えを自前で書く | オートスクロールと衝突判定を自分で持つことになる |
| 並び替え専用の別 UI を作る | 並び替えのためだけに画面を増やすことになる |

## 影響

- 依存が 2 つ増える。`overlayscrollbars-react` と `@dnd-kit/*`。**追加は承認済み** (2026-08-21)
- スクロール位置の復元と「選択行までスクロール」は、自前スクロールバーのビューポートに対して行う
- コンソールも同じスクロールバーを使う。見た目を揃える
- フェーズ 1 の時点で「仮想化 + 自前スクロールバー + 平坦化」を通しておく。フェーズ 3 の並び替えがここに乗る
