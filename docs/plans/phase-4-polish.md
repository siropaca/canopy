# フェーズ 4: 仕上げ

## 目的

常用できる状態にする。  
毎日起動して使うので、起動の速さと見た目のずれの無さを詰める。

## やること

- [x] スプリッタのドラッグ中に App 全体が再描画されるのを測る。いまは一時値をストアに書いているので、
      pointermove ごとに詳細ペインとステータスバーが再描画される (フェーズ 1 では体感の引っかかりは無し)
- [x] behind / ahead / 未コミットのチップが ツリー・詳細ペイン・ステータスバーで別々に書かれている。
      共通部品にするかは、モックが 3 箇所で別デザインなので見た目の詰めと合わせて判断する
- [x] rebase がコンフリクトで止まっているリポジトリの見せ方を決める。いまは `detached: <ハッシュ>` になる
      ([phase-2-write.md](phase-2-write.md) の「残した振る舞い」)
- [x] アプリ終了時に実行中の子プロセスを kill する ([../adr/0009-concurrency-and-refresh.md](../adr/0009-concurrency-and-refresh.md))。
      締め切りでの kill はフェーズ 2 で入れた。**孫プロセス (`ssh`) も一緒に扱う。**
      `kill_on_drop` は直の子だけを殺すので、打ち切ったあと `ssh` が残る (実測)。
      プロセスグループを作って、グループ単位で kill する形になる

- [x] モックと 1 つずつ見比べて差分を潰す。色、寸法、余白、アイコン、文言
- [x] 一括フェッチの結果が 1 件でも届かないと、フェッチのボタンが無効のまま戻らない。
      取りこぼしの検出をどう置くか決める (フェーズ 3 から持ち越し)
- [x] コンソールの出力に上限を置くか決める。いまはタブを閉じるまで積み上がる。
      入れるなら黙って捨てずに「古い出力を省略した」と出す (フェーズ 3 から持ち越し)
- [x] `consoleOpen` を UI ストアからコンソールのストアへ移すか決める。
      ウィンドウを隠している間の「見えているか」の判定を足すなら、置き場所を先に決める (フェーズ 3 のレビューから)
- [x] 打ち切ったときの stdout / stderr を残す。いまは空になる
      ([phase-2-write.md](phase-2-write.md) の「見送ったもの」)
- [x] 自前スクロールバーの見え方を詰める。太さ、色、出るタイミング
- [x] 常駐時のメモリと起動時間を測る。目標は常駐 150MB 以下・起動 1.5 秒以内
- [x] 閉じて復帰したときに読み込みが走らないこと (常駐の効果が出ているか)
- [x] ウィンドウの位置とサイズを保存して復元する
- [x] **ウィンドウを閉じてもプロセスを終了しない。** 隠すだけ ([../adr/0011-residency.md](../adr/0011-residency.md))
- [x] メニューバーのアイコンから復帰する。メニューに「終了」を置く
- [x] 二重起動を防ぐ。2 個目の起動は既存のウィンドウを前面に出す
- [x] メニューバーのメニューに「終了」を置く。閉じても終了しないので、終わる手段が必要
- [x] `pnpm tauri build` で macOS 向けにビルドする。Applications に置いて起動する
- [x] **Finder から `.app` を起動して git が動くことを確認する。** ターミナルからの `pnpm tauri dev` とは PATH が違う
- [x] サイドバーの自前ツールチップ ([phase-1-read.md](phase-1-read.md) から回ってきた項目)。**フェーズ 3 で実装済み** (`src/features/sidebar/Tooltip.tsx`)
- [x] 常用しながら気づいたことを [../pitfalls.md](../pitfalls.md) と v2 の候補に書き出す

## 決めたこと

依存を 1 つ足した。`libc` (プロセスグループの kill)。  
`tauri` に `tray-icon` の feature を、`tokio` に `io-util` を足した。  
**`tauri-plugin-single-instance` は入れなかった** ([ADR-0011](../adr/0011-residency.md) の注記)。

新しく書いた ADR。

| # | 判断 |
| --- | --- |
| [ADR-0020](../adr/0020-process-group-kill.md) | 子プロセスはグループごと畳む |

決めたこと。

- **rebase の途中は detached と分ける** (`HeadKind::Rebasing`)。見出しは `リベース中: <ブランチ>`、
  詳細は `リベース中 (<ブランチ>)`。文言は `shared/lib/headLabel.ts` の 1 本。
  **中断する手段は持たない。** `git rebase --abort` はターミナルで行う ([../specs/ui.md](../specs/ui.md) の「リベース中」)
- **チップは共通部品にしない。** ツリーの行 (地なし・`margin-left:7px`・`gap:3px`)、
  リポジトリ見出し (地あり・高さ 16px・`gap:2px`)、ステータスバー (地なし・`gap:4px`・12px) は
  地も寸法も間隔も違う。共通化すると props で分岐するだけの部品になる。
  共有しているのはアイコン (`shared/ui/icons.tsx`) で、そこは既に 1 本。
  **モックとのずれは共通化ではなくテストで縛った** (`src/test/mock-css.test.ts`)
- **`consoleOpen` は UI ストアに残した。** 永続化する UI 状態なので `paneWidth` と同じ置き場所でよい。
  足りなかったのは置き場所ではなく判定材料で、`windowVisible` を UI ストアに足して
  `isConsoleShowing` に条件を 1 つ増やした (定義は `store/consoleActions.ts` の 1 本のまま)
- **ウィンドウの位置とサイズは Rust が持つ。** `save_ui_state` は受け取った `window` を捨てる。
  フロントが読み込んだ時点の値を送り返すと、動かしたあとの位置が古い値で上書きされる
- **書き出すのは隠すときと終了するときだけ。** `Moved` / `Resized` はドラッグ中に何十回も来る
- **スプリッタは幅を「値」ではなく「読み方」で受ける。** 値で受けると呼び出し側が幅を購読することになり、
  pointermove ごとに画面全体が作り直される (実測で 10 移動 = 詳細ペイン 10 回)
- **一括フェッチの見張りは「最後に届いてから」数える。** 全体の締め切りにすると、
  リポジトリが増えるだけで誤検知する
- **自前スクロールバーは値を変えなかった。** 実測値を [../design-system.md](../design-system.md) に書き出した

### 直したもの

- **スプリッタのドラッグで画面全体が作り直されていた。** `App` が幅を購読していたので、
  pointermove ごとに詳細ペイン・ステータスバー・サイドバーが再描画されていた (実測 10/10)。
  幅を「読み方」で渡す形にして 0 回にした
- **`.badge` の余白がモックの倍だった。** flex の `gap: 4px` に加えて `margin-left: 4px` を持っていた
- **`.badge` だけ文字の太さを戻していた。** モックは見出しの 600 を継いでいる
- **ワークツリー名に等幅数字が掛かっていた。** 数字を出さないので外した
- モック側も 5 件直した。`gone` の余白が他のインジケーターと揃っていない / 検索欄の右余白が
  クリアボタンに足りていない / クリアボタンの位置が入力欄とずれている / ステータスバーの数字が
  等幅でない / コンソールの「出力はまだありません」が親と二重に余白を持っている

### 残した差分

要素が違うために出るものだけ。`src/test/mock-css.test.ts` の `ignore` に理由付きで並べてある。

- 検索欄のアイコン (モックは背景画像、実装はインライン SVG)
- クリアボタン (モックは文字の `✕`、実装はインライン SVG)
- 詳細ペインの余白 (実装はスクロール領域を分けているので、余白を持つのは中身の側)
- コンソールの空表示、トーストのリンク、メニューの項目 (モックは div / span、実装は p / button)

### 残した振る舞い

- **`.app` に署名も公証もしていない。** 個人利用なので当面やらない (「やらないこと」のとおり)
- **冷えたファイルキャッシュの初回起動は 2.07 秒。** 目標の 1.5 秒を超えるが、
  常駐するので 2 回目以降は起きない。常駐そのものがこの対策になっている
- **メニューバーのアイコンが macOS 26 に畳まれる。** アプリ側では制御できない。
  ユーザーが `•••` から出すか、`Cmd` を押しながら並べ替える

## レビューで出たこと

5 観点をサブエージェントに投げた (仕様の一致 / 正しさ / テスト / 設計 / ドキュメント)。  
指摘は 53 件 (仕様 7 / 正しさ 8 / テスト 13 / 設計 8 / ドキュメント 17)。  
重複を除くと 40 件ほどで、採用 37 件、見送り 3 件。

**ドキュメント観点がいちばん効いた。** 高が 3 件あり、どれも**今回の変更で自分が古くしたもの**だった。

### 表に出る不具合として直したもの

- **detached HEAD から始めた rebase が「リベース中: detached HEAD」と出る。**
  git は `head-name` を省略せず、detached から始めると文字列 `detached HEAD` を書く。
  「`head-name` が無ければ detached にフォールバック」という前提が誤りだった。
  一時リポジトリで再現を取って直し、統合テストを足した
- **一括フェッチを畳んだあと、遅れて届いた結果が個別トーストを 11 件積む。**
  上限 6 を超えて、直前に出した集約のトーストごと押し出される
- **同じく、遅れた結果が `endRun` を二重に呼んで、無関係な後続操作の「実行中」を解く。**
  畳んだ id を覚えて、届いたときに 1 回だけ外す形にした
- **見張りの猶予 60 秒が、長いプルの後ろに詰まったフェッチを誤検知する。**
  フェッチは同じリポジトリの書き込みロックを待つので、正しく 600 秒無音になり得る。
  `op_kind.rs` の 600 + 30 に合わせて 630 秒にした
- **`Cmd+H` と最小化で「ウィンドウが見えているか」が更新されない。** Rust のウィンドウ
  イベントに出てこない。**WebView の `visibilitychange` に寄せた** (実測で最小化を拾えることを確認)。
  Rust から送るイベントは消した
- **ウィンドウを戻しても、見えているタブの赤いドットが消えない。** 印を立てる側だけ足していた
- **一括フェッチ中にリストから消したリポジトリの結果で、コンソールのタブが復活する**
- **`collect` の `wait` に上限が無い。** パイプを閉じてから居座る子がいると、
  締め切りを指定した呼び出しがそのまま待たされる
- **`capBlocks` は上限 1 のとき全件返す。** `slice(-0)` が `slice(0)` になる
- **`on_window_event` がイベント元のウィンドウを見ていない。** いまは 1 枚なので実害は無いが、
  2 枚目を足すと「サブウィンドウが閉じずに本体が消える」
- **保存した位置が無いと、ウィンドウが画面の外に出る。** レビューの反映で
  `UiState` からウィンドウを外したときに、保存が空の状態で起動して見つけた。
  OS 任せの初期位置が「メニューバーの 977px 上」だった (実測)。`tauri.conf.json` に
  `"center": true` を足した

### 仕組みに落としたもの

- **固定した環境変数と引数が「実際に子プロセスに渡っている」ことを縛った。**
  一覧を作る関数の戻り値だけを見ていたので、`build_command` がそれを使うのをやめても
  3 通りとも素通りしていた (テスト観点の最大の穴)
- **ウィンドウの位置を戻すかどうかの判断を純粋関数に切り出した** (`geometry_to_apply`)。
  `is_usable` / `is_on_screen` は厳しく縛れていたのに、**それを呼ぶ側**が見られていなかった
- **控える価値があるかの判断も 1 本にした** (`worth_keeping`)。ついでにフルスクリーンを弾いた。
  フルスクリーンの枠をそのまま戻すと、タイトルバーがメニューバーの裏に入って掴めなくなる
- **`UiState` からウィンドウの位置を外して `Registry` 直下へ移した。** フロントと共有する DTO に
  「どちらの向きにも流れないフィールド」が残っていた
- **モックとの突き合わせに `padding-left` / `padding-right` / `box-shadow` / `min-width` /
  `min-height` を足した。** 影と最小幅のずれが見えていなかった
- **`Registered` を `collect` に所有させて、`wait` の直後に外す。** ADR-0020 が
  「pid は割り当て直されない」を根拠にしているのに、控えが `wait` より長生きしていた
- **`kill_all` が「実際に畳んだ数」を返すようにした。** 控えの数を返すと終了時のログが実際より多い
- **出力の読み取り失敗を `GitError::Output` に分けた。** `Spawn` と混ぜると「git が無い」を疑う
- **`spawn_in(&ChildGroups, ...)` の縫い目を作った。** グローバルに直結していると、
  終了時の一括 kill を試すテストが同時に走っている他のテストの git まで撃つ
- **`toggleConsolePanel` の「閉じるときは印を触らない」を、見ているタブに印が付いた状態で縛った**
- pitfalls に「Rust の子プロセス」の節を作って、UI とエージェント運用の節に紛れていた 3 件を移した

### 見送ったもの

- **アプリ終了時の kill が `git pull --rebase` も撃つ。** rebase が途中で残る。
  種別で分けても、親が死んでパイプが閉じた時点で `SIGPIPE` で死ぬので守れない。
  **残った rebase はこのフェーズで「リベース中」として画面に出る**ようになったので、
  ターミナルで戻せる。終了前に確認を出すかは v2 の判断
  ([../adr/0020-process-group-kill.md](../adr/0020-process-group-kill.md) の「影響」に書いた)
- **一括操作の見張りを操作の種別ごとに持つ。** v1 の一括操作はフェッチだけ。
  2 種類目を足すときに一般化する (フェーズ 3 の同じ見送りと揃えた)
- **`Splitter` を `onDelta` にして軸を名前から外す。** コンソールの高さのリサイズは v2。
  そのときに `width` / `height` ごと直す
- **`save_window` の「待っている間に動いた」経路のテスト。** 保存中に `record_window` を
  差し込む手段が無い。ドラッグ中は書かないので窓も狭い
