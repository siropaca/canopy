# Canopy

IntelliJ IDEA の Git ツールから日常的に使う部分だけを取り出した、macOS 向けの軽量デスクトップアプリ。  
複数リポジトリのブランチを 1 つのツリーで俯瞰して、チェックアウト・フェッチ・プル・プッシュを行う。

名前は森の樹冠 (canopy) から。  
複数の木 (リポジトリ) の枝を、上からまとめて見渡すという意味。

## なぜ作るか

Agentic Coding が主になって IDE を開く頻度が下がった。  
それでも Git 操作は IDEA の Git ツールが一番手に馴染む。  
Git 操作のためだけに IDE を起動するのは重く、メモリも食う。  
必要最小限の機能だけを Tauri で実装して、常時起動しておけるものにする。

IDEA に無くて欲しかったのは、**複数リポジトリを 1 つのビューで見られること**。  
モノレポではない 11 個前後のリポジトリを行き来するので、どのリポジトリに pull があるかを操作なしで把握したい。

## できること (v1)

- 複数リポジトリのブランチツリー表示 (ローカル / リモート / タグ)
- チェックアウト、フェッチ、プル、プッシュ、ブランチ名の変更
- behind / ahead / 未コミット / ワークツリーの状態表示
- ブランチとタグの横断検索
- 実行した git コマンドと出力を追えるコンソール

ログ・差分・コミット・リベース・マージ・ブランチの作成と削除は v2 以降。  
スコープの線引きは [docs/adr/0007-v1-scope.md](docs/adr/0007-v1-scope.md) にある。

## 状態

実装前。  
ドキュメントと UI モックのみが揃っている段階。

対象は **macOS のみ**。常駐して、メニューバーから呼び出す形にする。

## 動かす

```sh
mise install          # Node LTS と Rust
pnpm install
pnpm tauri dev
```

環境構築とコマンドの詳細は [docs/development.md](docs/development.md)。
