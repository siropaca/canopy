# フェーズ 3: 周辺

## 目的

日常的に使える状態にする。  
実行結果が追えて、検索で目的のブランチに辿り着けて、並びと状態が次回も保たれる。

## 前提

- [../specs/ui.md](../specs/ui.md) の「検索」「コンソール」「トースト」「スクロール」
- [adr/0005-persistence.md](../adr/0005-persistence.md) — 設定の保存
- [adr/0012-scrollbar-and-virtualization.md](../adr/0012-scrollbar-and-virtualization.md) — 並び替えを仮想化と両立させる方針

## やること

- [ ] コンソール。リポジトリごとのタブ、読み取り専用、行の色分け、タイムスタンプと作業ディレクトリ
- [ ] コンソールも仮想スクロールにする。出力は増え続ける
- [ ] タブの開閉、失敗を示す赤いドット、タブが無いときの表示
- [ ] トースト。成功は 4 秒、失敗は 9 秒。最大 6 件
- [ ] 一括操作は 1 件に集約する (`11 リポジトリをフェッチしました (失敗 2)`)。リポジトリごとに出すと上限を超えて失敗が押し出される
- [ ] 一括操作の実行中はそのボタンを無効にする
- [ ] 失敗トーストの `詳細を見る` からそのリポジトリのコンソールを開く
- [ ] 検索。ローカル・リモート・タグを横断。ヒットしたディレクトリを自動で開く
- [ ] 検索でヒットしないリポジトリも見出しを薄く残す
- [ ] リポジトリのドラッグ並び替え。**ドロップ位置は仮想化リストのインデックスから決める** (DOM のヒットテストに頼らない)
- [ ] 挿入線はリポジトリのブロック境界に描く。見出しの下に出すと配下の行の後ろに着地して線とずれる
- [ ] 端でのオートスクロール。並び替えても折りたたみ状態を保つ
- [ ] グループ化とローカルのみ表示のトグル
- [ ] ツリーペインのリサイズ
- [ ] 永続化。項目は [../specs/data-model.md](../specs/data-model.md) の `UiState`。まとめて保存する (デバウンス)
- [ ] 保存するのは**開いているキー** (`expanded`)。折りたたんでいるキーではない。既定が閉なので、逆にすると数百キーになる
- [ ] 読み込み時に存在しないキーを捨てる。`fetch --prune` で消えた ref のキーが溜まらないようにする
- [ ] 出力に含まれるトークンをマスクする ([../security.md](../security.md))

## テスト

| 層 | 内容 |
| --- | --- |
| フロント ユニット | 絞り込み。ヒット 0 のリポジトリが残ること。ローカルのみ表示との組み合わせ |
| フロント ユニット | 検索が永続化された折りたたみを書き換えないこと。検索を消すと元の状態に戻ること |
| フロント ユニット | 並び替え。前後どちらに落としても正しい位置に入ること。折りたたみキーが壊れないこと |
| フロント ユニット | トークンのマスク |
| コンポーネント | コンソールのタブ操作。失敗ドットが開くと消えること |
| Rust ユニット | 設定の保存と読み込み。スキーマのバージョンが違うときの移行 |

## 完了条件

- [ ] 再起動して、並び順・折りたたみ・ペイン幅・パネルの開閉が元に戻る
- [ ] 失敗した操作から `詳細を見る` でコンソールに辿り着ける
- [ ] 300 本のリモートブランチがある状態で検索がつまらない (1 文字打つごとに全 ref をツリー化するので、メモ化とデバウンスを入れる)
