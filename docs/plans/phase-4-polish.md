# フェーズ 4: 仕上げ

## 目的

常用できる状態にする。  
毎日起動して使うので、起動の速さと見た目のずれの無さを詰める。

## 前提

- [../design-system.md](../design-system.md)
- [../specs/ui.md](../specs/ui.md) 全体
- [adr/0011-residency.md](../adr/0011-residency.md) — 常駐と前面化
- [adr/0014-macos-only.md](../adr/0014-macos-only.md) — macOS のみ

## やること

- [ ] サイドバーのツールチップを自前の吹き出しにする。フェーズ 1 は `title` 属性で済ませている (モックは吹き出し)
- [ ] スプリッタのドラッグ中に App 全体が再描画されるのを測る。いまは一時値をストアに書いているので、
      pointermove ごとに詳細ペインとステータスバーが再描画される (フェーズ 1 では体感の引っかかりは無し)
- [ ] behind / ahead / 未コミットのチップが ツリー・詳細ペイン・ステータスバーで別々に書かれている。
      共通部品にするかは、モックが 3 箇所で別デザインなので見た目の詰めと合わせて判断する
- [ ] rebase がコンフリクトで止まっているリポジトリの見せ方を決める。いまは `detached: <ハッシュ>` になる
      ([phase-2-write.md](phase-2-write.md) の「残した振る舞い」)
- [ ] アプリ終了時に実行中の子プロセスを kill する ([../adr/0009-concurrency-and-refresh.md](../adr/0009-concurrency-and-refresh.md))。
      締め切りでの kill はフェーズ 2 で入れた。**孫プロセス (`ssh`) も一緒に扱う。**
      `kill_on_drop` は直の子だけを殺すので、打ち切ったあと `ssh` が残る (実測)。
      プロセスグループを作って、グループ単位で kill する形になる

- [ ] モックと 1 つずつ見比べて差分を潰す。色、寸法、余白、アイコン、文言
- [ ] 打ち切ったときの stdout / stderr を残す。いまは空になる
      ([phase-2-write.md](phase-2-write.md) の「見送ったもの」)
- [ ] 自前スクロールバーの見え方を詰める。太さ、色、出るタイミング
- [ ] 常駐時のメモリと起動時間を測る。目標は常駐 150MB 以下・起動 1.5 秒以内
- [ ] 閉じて復帰したときに読み込みが走らないこと (常駐の効果が出ているか)
- [ ] ウィンドウの位置とサイズを保存して復元する
- [ ] **ウィンドウを閉じてもプロセスを終了しない。** 隠すだけ ([../adr/0011-residency.md](../adr/0011-residency.md))
- [ ] メニューバーのアイコンから復帰する。メニューに「終了」を置く
- [ ] 二重起動を防ぐ。2 個目の起動は既存のウィンドウを前面に出す
- [ ] メニューバーのメニューに「終了」を置く。閉じても終了しないので、終わる手段が必要
- [ ] `pnpm tauri build` で macOS 向けにビルドする。Applications に置いて起動する
- [ ] **Finder から `.app` を起動して git が動くことを確認する。** ターミナルからの `pnpm tauri dev` とは PATH が違う
- [ ] 常用しながら気づいたことを [../pitfalls.md](../pitfalls.md) と v2 の候補に書き出す
