# ADR-0015: v1 に含める補助操作

- ステータス: 採用
- 日付: 2026-08-21

## 背景

[ADR-0007](0007-v1-scope.md) の「入れる」一覧は git の操作を中心に書いたので、  
[../specs/ui.md](../specs/ui.md) にある次の操作が一覧から漏れていた。

- ブランチ名 / タグ名 / パス / リポジトリ名 / GitHub URL のコピー
- Finder で表示、ターミナルで開く
- detached HEAD から直前のブランチに戻る

どれも `(v2)` を付けていないので v1 のつもりだが、スコープの一覧と食い違っていた。  
実現手段も決めていなかったため、実装時に `shell` プラグインへ手が伸びる恐れがあった。

## 決定

上の 3 種類は **v1 に含める。** 実現手段は次のとおり。

| 操作 | 手段 |
| --- | --- |
| コピー系 | フロントで `navigator.clipboard.writeText`。IPC を通さない。失敗したらトーストで知らせる |
| Finder で表示 | 専用コマンド `reveal_in_finder(repo_id)` → `open -R <パス>` |
| ターミナルで開く | 専用コマンド `open_in_terminal(repo_id)` → `open -a <アプリ> <パス>`。アプリ名は設定に持つ |
| 直前のブランチに戻る | 専用コマンド `checkout_previous(repo_id)` → `git checkout -` |

**`shell` プラグインの汎用実行は有効にしない。** `open` を叩く操作も意図ごとのコマンドとして持つ。

## 理由

- コピーは 6 箇所で使うので、無いと不便すぎる。`navigator.clipboard` は Tauri の WebView で使えるので依存を増やさずに済む
- Finder とターミナルは「ここから先はターミナルでやる」ときの導線。IDEA にもあって日常的に使う
- detached HEAD から戻る手段は、タグのチェックアウトを v1 に入れた以上必須。無いと自力で戻れない
- 汎用の shell 実行を開けると、[../security.md](../security.md) の「意図ごとにコマンドを分ける」原則が崩れる

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| コピーに `tauri-plugin-clipboard-manager` を使う | 依存が増える。`navigator.clipboard` で足りる |
| Finder / ターミナルを v2 に回す | ツールから抜ける導線が無いと、結局ターミナルを別に開くことになる |
| `shell` プラグインで `open` を実行する | 汎用実行の口が開く |
| ターミナルアプリを決め打ちにする | 使っているアプリと違うものが起動する。設定に持たせる |

## 影響

- 設定に「ターミナルアプリ名」が増える。既定値は決めておく
- `open` を実行する 2 コマンドは、パスの検証を通す (登録済みのリポジトリか、そのワークツリーか)
- クリップボードの失敗をトーストで出す。握りつぶさない
