# ADR-0023: 実行中をステータスバーに出す

- ステータス: 採用
- 日付: 2026-09-04
- [ADR-0009](0009-concurrency-and-refresh.md) の「実行中の扱い」を見直す

## 背景

[ADR-0009](0009-concurrency-and-refresh.md) は実行中の見せ方を「無効化と行を薄くするだけ。**スピナーは出さない**」と決めた。  
根拠は「操作のフィードバックがゼロだとユーザーが同じ操作を繰り返す」で、そこは無効化で足りるという判断だった。

フェーズ 5 まで常用して、**足りていない**ことが分かった。

- ボタンが灰色になるだけなので、押した直後は「効いたのか固まったのか」が分からない
- 薄くなるのは対象のリポジトリの行だけで、畳んでいれば見えない
- サイドバーの「更新」は読み取りなので実行中の印すら付かない。**押しても完全に無反応**

ネットワークを触る操作は数秒かかる。  
その間、画面のどこにも「いま何をしているか」が出ていない。

## 決定

**いま何をしているかをステータスバーの左端に出す。**

- 出す文言と優先順位は [../specs/ui.md](../specs/ui.md) の「ステータスバー」に置く
- 左端に回るアイコンを 1 つ添える。**止まっていないことが分かる最小限**
- 一括フェッチは進み具合を出す。11 件が順に返るので、残りが見えないと終わりが読めない
- 取り直しも出す。無効化はしないので、この表示だけが手がかりになる
- **行の薄さと無効化はそのまま残す。** どのリポジトリが対象かは行で見る
- **行にスピナーは出さない。** ADR-0009 のこの部分は変えない
- **詳細ペインには何も足さない**

## 理由

- **場所が固定なのがいちばん効く。** ツリーは畳めるしスクロールする。対象の行が見えていなくても、
  目の高さが決まっている場所に出ていれば「動いている」が分かる
- **1 行にまとまる。** 11 リポジトリを一括フェッチしても、増えるのは 1 行だけ。
  行ごとに出すと 11 個のスピナーが同時に回る
- **アイコンは 1 つだけ回す。** ADR-0009 がスピナーを避けたのは視覚的な騒がしさが理由で、
  1 つだけなら当たらない。文字だけだと更新のたびに差し替わっているのか止まっているのか読めない
- **取り直しも出す。** 「更新」を押して無反応なのがいちばん困る。
  ただし取り直しで**ボタンを無効にはしない** (`.git` の監視で頻繁に走るため。[ADR-0022](0022-auto-refresh.md))
- **進み具合を出すのは一括フェッチだけ。** 個別の操作は段数が可変で、途中経過を持っていない
  ([ADR-0018](0018-command-result-steps.md))

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| 実行中の行にスピナーを出す | 一括フェッチで 11 個同時に回る。畳んでいる行と画面外の行では見えない。「更新」では 1 個も出ない |
| ツリーの上端に不定のプログレスバーを流す | 動いていることは分かるが、何をしているかが分からない。フェッチとプルの区別が付かない |
| トーストを開始時にも出す | 上限 6 件を実行中のトーストが埋める。終了のトーストが押し出される ([../specs/ui.md](../specs/ui.md) の「トースト」) |
| ボタン自体をスピナーに差し替える | 押した本人しか見ない。コンテキストメニューやダブルクリックから始めた操作では何も出ない |
| 詳細ペインに出す | 選択している行と実行中のリポジトリは一致しない。選択を外すと消える |
| 進み具合を全操作で出す | 個別の操作は段数が可変で、Rust から途中経過を送る仕組みが要る。得られるのは数秒の見え方 |
| 件数だけ出す (`3 件を実行中`) | フェッチなのかプッシュなのかが分からない。待ってよい時間の見当が付かない |

## 影響

- `RepoStoreState.running` が本数から**操作の列**になる。`beginRun` が操作の種別を受け取る
- 取り直しの最中を持つ `reading` が増える。**`running` とは別にする。**
  混ぜるとボタンが取り直しのたびに無効になる
- ステータスバーが集計だけの表示ではなくなる ([../specs/ui.md](../specs/ui.md) の「ステータスバー」)
- 文言の組み立ては `shared/lib/activity.ts` の純粋関数 1 本に置く
- ADR-0009 の「スピナーは出さない。無効化と行を薄くするだけ」は、**行についてだけ**有効になる。
  [ADR-0009](0009-concurrency-and-refresh.md) の側にもその旨を注記する
- 実行中の文言を左端に差し込むので、**出入りのぶん右の集計が横に動く。**
  右端に置けば動かないが、いちばん見てほしいものを端に追いやることになるので取らない
