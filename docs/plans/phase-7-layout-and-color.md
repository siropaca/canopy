# フェーズ 7: 見出しの色と画面の出し分け

## 目的

常用して出た 4 つを入れる。

- リポジトリ見出しに色を付けて見分けられるようにする
- 選択を外して、サイドバーのフェッチで全リポジトリをフェッチできるようにする
- 詳細ペインを隠して、ツリーだけの細いウィンドウで置いておけるようにする
- 全体の色を青みのないグレーにして、並べて使っているツールと色味を揃える

## やること

### 1. 見出しの色

- [x] `UiState` に `repo_colors` を足す。色は名前 (`red` / `orange` / `yellow` / `green` / `blue` / `purple`)
- [x] 知らない色の名前は読み捨てる。設定ファイル全体を壊れた扱いにしない
- [x] リストから削除したリポジトリの色を捨てる (`expanded` と同じ場所)
- [x] トークンを 6 つ足す (モック・`tokens.css`・`design-system.md`)
- [x] 見出しの行を色で塗る。固定した見出しも同じ色。選択と薄い表示は色の上に乗る
- [x] リポジトリ見出しのメニューに `見出しの色` のサブメニューを置く。各項目に色見本を付ける
- [x] 色を選んだら選択を外す (レビューのあとユーザーが決めた)

### 2. 選択を外す

- [x] ツリーの行が無い所を左ボタンで押すと選択を外す。検索欄とスクロールバーは含めない
- [x] サイドバーのフェッチのツールチップを `フェッチ (すべて)` / `フェッチ (<リポジトリ名>)` にする

### 3. 詳細ペインの開閉

- [x] `UiState` に `detail_open` を足す。既定は表示
- [x] サイドバーの「パネル」グループに `詳細パネル` のトグルを置く
- [x] 隠している間はツリーが残りの幅を全部使う。スプリッタを出さない
- [x] `set_detail_open` コマンドで、ウィンドウの幅の下限を 720px / 360px で切り替える
- [x] 表示に戻すとき、720px より狭ければ 720px に広げる。画面の右端からはみ出すなら左へずらす
- [x] 起動時は保存した `detail_open` から下限を決めてから位置を戻す。保存する寸法の下限を 360px にする
- [x] 細いウィンドウで崩れないようにする。ステータスバーは折り返さずに切る、ダイアログとトーストはウィンドウの幅に収める

### 4. モックと仕様

- [x] モックに 3 つとも入れる
- [x] `specs/ui.md`・`specs/data-model.md`・`design-system.md`・`README.md` を直す

### 5. 全体の色

- [x] 面・境界・文字・選択・ボタンのトークンの値を青みのないグレーにする (モック・`tokens.css`・`design-system.md`)。意味の色と見出しの色は変えない
- [x] プライマリボタンとトーストのアイコンの文字を `--accent-fg`、入力欄 (検索欄とダイアログ) のフォーカスの枠を `--ring` にする
- [ ] README のスクリーンショットを撮り直す

## 完了条件

**実機での確認が残っている。** テストとモックでは確かめたが、ウィンドウの寸法と再起動はアプリを動かさないと見られない。

- [ ] 見出しの色を選ぶと見出しが塗られ、再起動しても残る
- [ ] 空いた所を押してからサイドバーのフェッチを押すと、全リポジトリがフェッチされる
- [ ] 詳細ペインを隠すとウィンドウを 360px まで細くでき、表示に戻すと 720px に広がる
- [ ] 細くしたまま再起動しても、同じ幅で戻る
- [ ] アプリで見て、色がモックと同じに出ている。プッシュと削除のダイアログのチェックボックスの印が読める

## やらないこと

- 任意の色の選択 ([adr/0024](../adr/0024-repo-heading-color.md))
- ブランチの行の色付け
- キーボードでの選択解除 ([adr/0008](../adr/0008-no-keyboard-shortcuts.md))
- 詳細ペインを隠している間の、詳細の代わりの表示 (ツールチップで詳細を出す、など)

## 決めたこと

| 何を | どう | 理由 |
| --- | --- | --- |
| 色の保存 | `UiState.repo_colors` に「id → 色の名前」 | [adr/0024](../adr/0024-repo-heading-color.md) |
| 知らない色の読み方 | `RepoColors` の `Deserialize` を手で書いて読み捨てる | `deserialize_with` は ts-rs が解釈できずに警告を出す |
| 色の一覧 | Rust の `RepoColor` を源にして、フロントは `shared/lib/repoColors.ts` を `satisfies` で縛る | 色を足したときに CSS・トークン・モックの足し忘れがテストで落ちる |
| 実行中の見出し | 文字だけ薄くして背景は塗り替えない (`busy`)。ヒットなし・エラーの薄い表示 (`dimmed`) と分けた | 一括フェッチの間じゅう色が消える (レビューで指摘) |
| ウィンドウのコマンド | `commands/window.rs` を足して 4 ファイルにした | 設定の読み書きでも git の操作でもない |
| 広げる判断 | `detail_layout` / `geometry_to_apply` の純粋関数に寄せ、Tauri に触る側は当てるだけ | Tauri のモックでは寸法が観測できず、配線にテストが付かない |
| 開閉の要求 | フロントで直列に送る | Tauri の async コマンドは並行に走る |
| 選択を外す場所 | 最後の行の下に 2 行ぶんの余白 | 仮想リストの器は行の高さぴったりで、長いツリーでは押せる所が無い |

依存は足していない。

## 確かめたこと

| 何を | どう |
| --- | --- |
| モック | ブラウザで確認した。色のサブメニューと色見本、見出しの塗り、色付きの見出しでも選択色が勝つこと、空いた所で選択が外れてツールチップが `フェッチ (すべて)` に戻ること、Ctrl+クリックでは外れないこと、長いツリーの一番下に 42px の空きがあること、詳細パネルの開閉でツリーが全幅になり戻すと元の幅に戻ること、360px 幅でステータスバーが 20px のまま右を切ること |
| テストに歯が立っていること | 実装を壊して落ちることを確かめた。自分で 10 通り、レビューで 101 通り。素通りした 20 通りのうち、純粋関数とフロントの分はテストを足して落ちるようにした |
| 全体の色 | 実装の CSS を読み込んだ確認用のページで、ダイアログのプライマリ・無効・破壊的なボタンの地と文字の色を計算値で確かめた。モックをブラウザで確認した。ツリー、フォーカスあり・なしの選択、コンテキストメニューのハイライト、詳細ペインのプライマリボタン、名前の変更ダイアログの入力欄のフォーカスとボタン、コンソール |
| 実機 | **未確認。** ウィンドウの幅の下限と広げ方、再起動後の復元はアプリを動かして確かめる必要がある |

`apply_detail_open` / `restore` / `set_detail_open` の Tauri に触る 1 行ずつの呼び出しにはテストが無い。  
`tauri::test` のモックは `set_min_size` などを何もせずに返すので観測できない。判断は純粋関数に寄せてあり、残りは実機で確かめる。

### 見送ったもの

| 指摘 | 理由 |
| --- | --- |
| `pane_width` が 679px を超えていると、720px に広げても詳細ペインが潰れる | フェーズ 7 より前からある制約 (720px のウィンドウと 760px のツリー)。直すにはツリーの寸法を Rust も持つことになる。ADR-0025 と仕様に制約として書いた |
| 起動の直後、UI 状態を読むまで一瞬だけ詳細ペインが出る | IPC 1 往復ぶん。読み込みまで詳細ペインを出さないようにすると、表示のときに逆向きに跳ねる |
| 読み込みの前に詳細パネルを押すと、読み込みで開閉が上書きされる | 読み込みは数十 ms。サイドバーのほかのボタンも同じ扱い |
| 細いウィンドウで、長いリポジトリ名のフェッチのツールチップが切れる | 40 文字を超えるリポジトリ名で起きる。先頭は読める |
| 青の見出しと、フォーカスがあるときの選択の青が近い | 明るさで分かれている (`#2c4466` と `#3d5a94`)。モックで並べて見分けられた。全体の色を変えたあとは、選択がグレー (`#555555`) になり 6 色のどれよりも明るい |
| メニューを閉じるクリックが下の行や空いた所にも届く (選択が動く) | フェーズ 7 より前からある。直すと行の選択の仕方も変わるので、別で決める |
| `repo_colors` そのものが map でないと設定全体が読めない | 他の項目の型が違うときと同じ扱い ([adr/0016](../adr/0016-store-without-plugin.md))。アプリはこの形を書かない |
| 名前が引けないときに id を出す分岐にテストが無い | 見えている選択は同じストアから平坦化した行なので通らない |
| Tauri に触る 1 行ずつの呼び出しにテストが無い | `tauri::test` のモックで観測できない。判断は純粋関数に寄せた。実機で確かめる |
| ADR-0026 が「選択を外す」と「名前に対象を出す」の 2 つを 1 本にしている | どちらも「全リポジトリのフェッチに戻る道」の一部で、片方だけでは背景が解けない |
