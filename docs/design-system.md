# デザインシステム

面と文字は青みのないグレーにして、Orca のダークテーマに揃える ([adr/0027-neutral-dark-palette.md](adr/0027-neutral-dark-palette.md))。  
青・緑・オレンジ・紫などの色相を持たせるのは意味の色と見出しの色だけ。  
値の唯一の参照元は [mock/tree.tmpl.html](mock/tree.tmpl.html) の `:root` にある CSS 変数。  
`tree.html` は生成物なので参照しない。  
実装では同じ名前の CSS 変数を `src/shared/styles/tokens.css` に置き、モックからコピーする。

**下の表の値もテストの比較対象。**  
モック・`tokens.css`・この表の 3 つが一致していないと `src/shared/styles/tokens.test.ts` が落ちる。  
hex は小文字で書く。  
Prettier が `tokens.css` を小文字に正規化するので、大文字で書くと片方だけ直せなくなる。

### 見出しの色

リポジトリ見出しに塗る色 ([adr/0024-repo-heading-color.md](adr/0024-repo-heading-color.md))。  
ユーザーが見分けるために選ぶもので、意味は持たない。  
どれも `--fg-strong` の白い太字が読める暗さに揃えてある。  
保存するのは名前 (`red` など) だけで、値はここにしか無い。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--head-red` | `#5c3434` | 見出しの色の「赤」 |
| `--head-orange` | `#5e4128` | 見出しの色の「オレンジ」 |
| `--head-yellow` | `#57502a` | 見出しの色の「黄」 |
| `--head-green` | `#2f4a33` | 見出しの色の「緑」 |
| `--head-blue` | `#2c4466` | 見出しの色の「青」 |
| `--head-purple` | `#4a3862` | 見出しの色の「紫」 |

### 意味の色

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--track` | `#548af7` | behind、リモート名、リンク、改名した変更ファイル (`R`)、並び替えの挿入線、プッシュダイアログのコミットの点 |
| `--ahead` | `#62a85e` | ahead |
| `--cur` | `#e8b73d` | 現在ブランチのタグアイコン |
| `--dirty` | `#e8a33d` | 未コミット |
| `--gone` | `#9a5f5f` | 追跡ブランチが消えている |
| `--folder` | `#a1a1a1` | フォルダアイコン |
| `--icon` | `#a1a1a1` | アイコンの既定色 (ブランチ、タグ、サイドバー) |
| `--wt` | `#b28fd0` | ワークツリー |

色は意味に紐づける。  
青は「取り込むもの」、緑は「出すもの」、オレンジは「手元の未確定」、紫は「別のワークツリー」。  
新しい意味を足すときは既存の 4 色を使い回さず、表に追加する。  
**例外は「見出しの色」だけ。** ユーザーが見分けるために選ぶ色で、意味を持たない。  
そのため意味の色とは別のトークンにしてある。

**同じ値の別トークンを 1 つにまとめない。**  
`--folder` と `--icon`、`--head` と `--border`、`--border2` と `--on` と `--badge-bg`、`--btn` と `--accent`、`--faint` と `--ring` などは値が同じだが意味が違う。  
まとめると片方だけ変えたいときに全部が動く。

**影とオーバーレイの黒はトークンにしない。**  
`rgba(0,0,0,.4)` などは色ではなく効果で、意味に名前を付けられない。  
モックにもそのまま残してある。

検索欄のアイコンは data URI の中に色を書いている。  
`url()` の中では CSS 変数が使えないので、ここだけモックに生の値が残る。  
実装ではインラインの SVG にして `currentColor` で塗る。

## 寸法

| 変数 / 値 | 用途 |
| --- | --- |
| `--row: 21px` | ツリーとリストの行高 |
| `--console-line: 19px` | コンソールの出力 1 行ぶんの高さ (仮想化に渡す初期値) |
| `13px` | 本文のフォントサイズ |
| `12px` | 補助テキスト、ステータスバー、メニューの副情報 |
| `13px` | ツリー内のアイコン、インデントの 1 段 |
| `11px` | インジケーターの矢印と丸 |
| `10px` | バッジ内のアイコン (見出しのサマリ) |
| `36px` | サイドバーの幅 |
| `30px` | サイドバーのボタン |
| `360px` | ツリーペインの初期幅 (240〜760px でリサイズ可) |
| `230px` | コンソールパネルの高さ |
| `26px` | ツールバー・タブバーの高さ |
| `20px` | ステータスバーの高さ |

角丸は使わない。  
例外はダイアログ (`8px`) とダイアログ内のボタン・入力欄 (`4〜5px`)。  
余白は詰める。行の左右パディングは 5〜7px。

## アイコン

- すべてインラインの SVG。`viewBox="0 0 12 12"` か `0 0 16 16`
- `fill: none` / `stroke: currentColor` / `stroke-width: 1.1〜1.35`
- **例外は未コミットの丸だけ。** 塗りつぶすので `fill: currentColor` / `stroke: none`
- 色は class で当てる。SVG に色を直接書かない
- 意味が違うものに同じ形を使わない。ブランチ、タグ、フォルダ、ワークツリーはすべて別の形
- **動かすのは実行中の輪だけ。** 行やボタンは動かさない。
  OS で「視差効果を減らす」を選んでいる人には回さない

| アイコン | 意味 |
| --- | --- |
| タグ (斜め・オレンジ) | 現在のブランチ |
| ブランチ (ノード 2 つと分岐) | 通常のブランチ |
| タグ (横向き・グレー) | git のタグ |
| フォルダ | スラッシュで畳んだディレクトリ |
| ワークツリー (2 枚の四角・紫) | 別のワークツリーにチェックアウトされている |
| 塗りつぶした丸 | 未コミット |
| 斜め下の矢印 | behind (取り込む) |
| 斜め上の矢印 | ahead (出す) |
| 斜め下の破線矢印 | フェッチ (まだ取り込んでいない) |
| 切れ目のある輪 (回る) | 実行中。**ステータスバーに 1 つだけ** ([adr/0023-progress-in-the-status-bar.md](adr/0023-progress-in-the-status-bar.md))。サイドバーの「更新」の丸い矢印とは別の形にする |

## インジケーターの色と並び

未コミット (オレンジ) → behind (青) → ahead (緑) の順に並べる。  
行のどこに何が出るかは [specs/ui.md](specs/ui.md)。

数字は等幅にして桁がずれないようにする (`font-variant-numeric: tabular-nums`)。

## 状態の表し方

- **現在のブランチ** — オレンジのタグアイコンのみ。太字にしない、背景色を付けない
- **選択行** — 背景色。フォーカスがあれば明るいグレー、なければ暗いグレー
- **無効** — 文字色を `--disabled` に落として、ホバー効果を消す。**プライマリの地と枠も通常状態に戻す。** プライマリの地 (`--btn` / `--accent`) の上に `--disabled` を乗せると読めず、押せるように見える ([pitfalls.md](pitfalls.md))

何をどの状態で出すかは [specs/ui.md](specs/ui.md)。ここは見え方だけ。

## スクロール

**ネイティブのスクロールバーは出さない。** 自前のスクロールバーを描く ([adr/0012-scrollbar-and-virtualization.md](adr/0012-scrollbar-and-virtualization.md))。  
細く、触っている間だけ出す。掴むと濃くなる。IDEA に寄せる。  
ツリーとコンソールで同じものを使う。  
仮想スクロールを使うので、スクロール量から全体の件数を推測させない前提で設計する。

値は `src/shared/ui/ScrollArea.module.css` にある。**トークンにはしない。**  
モックに自前スクロールバーが無いので、トークンにするとモックと 1:1 で揃わなくなる。

- 枠 10px、上下左右に 2px の余白 → **つまみは 6px**
- 角丸 5px、つまみの最小の長さ 24px
- 溝は透明。つまみは `--dim` の 45%、ホバーで 70%、掴んでいる間は 100%
- **ポインタが領域の中にある間だけ出す。** 離れて 0.5 秒で消える

出す条件を「スクロールしている間だけ」にすると、つまみを掴みにいけない。  
領域に入った時点で出す方を採った。
