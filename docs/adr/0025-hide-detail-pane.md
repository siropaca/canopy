# ADR-0025: 詳細ペインを隠せるようにする

- ステータス: 採用
- 日付: 2026-09-25

## 背景

[../specs/ui.md](../specs/ui.md) は「詳細ペインは常に表示する。切り替えは持たない」と決めていた。

常用すると、ツリーだけ見ていれば足りる時間が長い。  
behind / ahead / 未コミットはツリーの行に出ているので、詳細ペインを見るのは操作するときくらいになる。  
その間も詳細ペインが幅を取り、ウィンドウの幅の下限が 720px なので、ウィンドウを細くして画面の端に置いておくこともできない。

## 決定

**サイドバーのボタンで詳細ペインを隠せるようにして、隠している間はウィンドウの幅の下限を 360px に下げる。**

- ボタンはサイドバーの「パネル」グループ、`コンソール` の下に置く。名前は `詳細パネル`、トグル
- 隠している間はツリーが残りの幅を全部使う。スプリッタも出さない
- 状態は `UiState.detail_open` に保存する。既定は表示
- 表示している間の下限は今までどおり 720px
- **表示に戻すとき、ウィンドウが 720px より狭ければ 720px に広げる。** 広げた結果が画面の右端からはみ出すなら、はみ出さない位置まで左へずらす
- 下限の切り替えと広げる処理は Rust 側で行う。フロントは `set_detail_open` を呼ぶ。**続けて押しても要求は 1 つずつ順に送る**
- 起動時は、保存してある `detail_open` から Rust が下限を決めてから位置とサイズを戻す。詳細ペインを出しているのに細い値が残っていたら、広げてから戻す

## 理由

- **下限を下げないと隠す意味が半分になる。** 720px のままだと、ツリーが横に伸びるだけで画面の端に置いておけない
- **表示に戻すときに広げる。** ツリーの幅は `pane_width` で固定しているので、細いまま詳細ペインを出すと詳細ペインが幅 0 に潰れる
- **ウィンドウを動かすのは Rust 側。** ウィンドウの位置と寸法を知っているのは Rust だけにしてある  
  ([../specs/data-model.md](../specs/data-model.md) の `UiState`)。  
  フロントから Tauri のウィンドウ API を叩くには権限 (capabilities) を足すことになり、  
  フロントがウィンドウを動かせる範囲が広がる ([../security.md](../security.md))。  
  自前のコマンドなら、できることが「下限の切り替えと、足りない幅を広げる」だけに決まる
- **要求を直列に送る。** Tauri の async コマンドは呼び出しごとに並行に走るので、続けて押すと後の要求が先に効いて、  
  隠しているのに下限が 720px のまま残ることがある
- **360px の根拠。** サイドバー 36px とツリーの最小幅 240px で 276px。  
  そこにブランチ名とインジケーターが並んで読める余裕を足した
- **起動時の下限は Rust が決める。** フロントの読み込みを待つと、細く保存したウィンドウを 720px の下限で戻してしまう
- **起動時にも広げる。** 表示に戻した直後に強制終了すると、古い細い幅と `detail_open: true` が一緒に保存に残る

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| 下限は 720px のままにする | ツリーが横に伸びるだけになる。細いウィンドウで置いておけない |
| 下限を常に 360px にする | 詳細ペインを出したまま細くすると、詳細ペインが潰れてツリーがはみ出す |
| フロントから Tauri のウィンドウ API を呼ぶ | capabilities に権限を足すことになり、フロントからウィンドウを自由に動かせるようになる。広げる計算にテストが付けにくい |
| スプリッタで詳細ペインを 0 まで縮められるようにする | 隠れているのか壊れているのかが分からない。戻し方が見えない |
| 表示に戻すときに広げず、ツリーを縮める | `pane_width` を勝手に書き換えることになり、ユーザーが決めた幅が戻らない |
| 広げる先を `pane_width` から計算する | ツリーとスプリッタの寸法を Rust も持つことになり、突き合わせが要る。下の制約は前からあるもので、ウィンドウを広げれば出る |

## 影響

- `tauri.conf.json` の `minWidth` は 720px のまま。詳細ペインを出している状態が既定
- 保存するウィンドウの寸法の下限 (`is_usable`) は 360px に下がる。細く保存したウィンドウも戻せるようにするため
- ウィンドウが細くなるので、ステータスバーは折り返さずに右を切る。ダイアログ・トースト・コンテキストメニューはウィンドウの幅に収める
- 詳細ペインを隠している間も選択はできる。操作はサイドバーとコンテキストメニューから行う
- **`pane_width` が 679px を超えていると、720px に広げても詳細ペインは潰れる。** 720px のウィンドウと 760px までのツリーはフェーズ 7 より前から両立していない。  
  隠す → 戻す、はそこへ至る道を 1 つ増やす
- [../specs/ui.md](../specs/ui.md) の「詳細ペインは常に表示する」を外す
