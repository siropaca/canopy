# ADR-0007: v1 のスコープ

- ステータス: 採用
- 日付: 2026-08-21

## 背景

IDEA の Git ツールは高機能だが、実際に使っているのはごく一部。  
全部を作ろうとすると完成しない。

## 決定

v1 は次の範囲に限る。

**入れる**

- 複数リポジトリのブランチツリー (ローカル / リモート / タグ)
- チェックアウト、フェッチ、プル、プッシュ (強制プッシュを含む)、ブランチ名の変更
- behind / ahead / 未コミット / ワークツリー / 追跡ブランチ消失の表示
- ブランチとタグの横断検索
- git の実行結果を見るコンソール
- リポジトリの追加・削除・並び替え

**入れない**

- コミットログ、差分の表示
- コミット
- リベース、マージ
- ブランチの作成・削除、タグの削除
- ワークツリーの作成
- 追跡ブランチの変更、お気に入り

## 理由

毎日使うのは「今どこにいて、pull があるか」を見て、切り替えて、取り込んで、出すこと。  
ログと差分はターミナルと GitHub で見ている。  
コミットは Agentic Coding 側でやることが多い。

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| ログと差分も v1 に入れる | 実装量が倍以上になる。右ペインの設計もやり直しになる |
| 表示専用にして操作を持たない | 操作のために IDEA を開くなら意味がない |

## 影響

- v2 以降の項目は、コンテキストメニューにグレーで置いて位置だけ確保する。あとで足すときに配置を考え直さない
- **コミットは v2 の最初の候補。** 右ペインに変更ファイルの一覧を出しているので、そこを起点に広げる
- リベースとマージは操作の見せ方が難しい。ログが入ってから設計する
