# ADR-0001: Tauri + React で作る

- ステータス: 採用
- 日付: 2026-08-21

## 背景

IDE を開かずに Git 操作をしたいのが動機なので、**軽さが機能より優先**される。  
常時起動しておいて、必要なときにすぐ前面に出せる必要がある。

## 決定

Tauri 2 + React + TypeScript + Vite で作る。

## 理由

- Electron よりメモリ使用量とバイナリサイズが小さい。IDE を開かない理由が「重いから」なので、ここは譲れない
- git を叩くのは Rust 側でできる。認証やプロセス管理を扱いやすい
- フロントは普段使っているスタックなので、UI の作り込みに時間を割ける

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| Electron | メモリとサイズが目的に反する |
| SwiftUI ネイティブ | UI の作り込みが一番重い部分で、慣れていない分だけ遅くなる |
| TUI (ターミナル) | ツリーとマウス操作を IDEA に寄せたいので合わない |

## 影響

- Rust のツールチェインが必要になる
- WebView は macOS の WKWebView に依存する。ブラウザ差異は考えなくてよい
- 配布は署名の話が出てくるが、個人利用なので当面は考えない
