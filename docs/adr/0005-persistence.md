# ADR-0005: 設定は JSON ファイルに保存する

- ステータス: 採用
- 日付: 2026-08-21

## 背景

保存したいのは、リポジトリの一覧と UI の状態 (項目は [../specs/data-model.md](../specs/data-model.md) の `UiState`)。  
どれも小さく、検索も集計も要らない。

## 決定

Tauri の store プラグインで JSON ファイルに保存する。

## 理由

- データが小さく構造も単純。SQLite を入れる理由がない
- 中身を直接読める。壊れたときに手で直せる
- リポジトリのパスは Rust 側だけが持つ設計 ([../security.md](../security.md)) と相性が良い

## 検討した他の案

| 案 | 採らなかった理由 |
| --- | --- |
| SQLite | 過剰。マイグレーションの手間が増える |
| localStorage | フロント側に保存すると、パスをフロントが持つ設計になってしまう |

## 影響

- スキーマにバージョン番号を持たせる。形が変わったときに移行できるようにする
- 保存は書き込みのたびではなく、まとめて行う (デバウンス)
